# Healthify

A personal calorie log for iPhone. Meals, streaks, and targets stay in the phone browser. This repository is the public app, hosted free on GitHub Pages.

https://karthick-s4.github.io/Healthify/

## On an iPhone

1. Open the link in Safari.
2. Tap Share, then Add to Home Screen.
3. Open the Healthify icon and set a 4-digit PIN plus a daily calorie target.

Log food in plain words: `3 idli`, `apple 150g`, `chicken biryani ate out`. Turn on Ate out for restaurant or delivery food.

## Updates

Pushing to `main` publishes a new version. On the iPhone, swipe Healthify away in the app switcher and open the icon again.

## On this computer

```bash
npm install
npm test
npm run dev
```

The dev address works on the same Wi-Fi while this computer is awake. The GitHub Pages link works when the computer is off.
